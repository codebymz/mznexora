## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/codebymz/mznexora.git
cd mznexora

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env.local
# → Add your NEXT_PUBLIC_SITE_URL and email config

# 4. Start development server
npm run dev

# 5. Open in browser
# http://localhost:3000
```
