# MZ Nexora Brand Assets & Logos Directory

Is folder me aap apni brand logo files (PNG, SVG, JPG, WebP) rakh sakte hain:

### Recommended File Names:
- `public/assets/logos/logo.png` — Main full logo (Navbar / Footer)
- `public/assets/logos/logo-icon.svg` or `logo-icon.png` — Icon mark / Favicon / Monogram
- `public/assets/logos/logo-dark.png` / `logo-light.png` — Dark/Light variants

### How it works:
Standard path: `/assets/logos/logo.png` ya `/assets/logos/logo.svg`
App is path se logo images load karegi.
